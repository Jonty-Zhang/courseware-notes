# 源稿 Markdown 约定（build_docx.py）

| 写法 | 效果 |
|---|---|
| `# 一、…` `## （一）…` `### 1. …` `#### 例 1-1 …` | 一至四级标题；编号自己写，脚本不自动编号 |
| `$F_x=F\cos\theta$` | 行内公式 → 可编辑 Word 公式 |
| 单独一段 `$$ … $$`（可跨行） | 独立公式，居中、无首行缩进 |
| `==关键结论==` | 浅蓝色文字，不加粗 |
| `**做法：**` | 加粗标签 |
| `![图题](c4_p26.png){width=48%}` | 居中插图，图题放在下方并自动加"图 N " |
| `Table: 表题` + 空行 + 管道表格 | 原生 Word 表格，表题放在上方并自动加"表 N "，单元格段距为 0 |
| `::: example` … `:::` | 例题块；`--drop-examples` 时整块删除 |
| `〔4-p26〕` | 课件页码引用，普通文字 |

注意：

- 公式里不要写中文；单位用 `\ \text{N}`、`\text{kN·m}`。
- 矢量用 `\vec F`，有向线段用 `\overrightarrow{OO'}`。
- 段落里不要用 Markdown 有序/无序列表，用（1）（2）这样的文字编号，保证 Word 里格式统一。
- 例题块里的图只出现在含例题版；知识点部分需要的图（如分类示意图）放在块外，两版都有。
- 一个 `::: example` 块里不要嵌套另一个块。
