# 逐页清单格式（work/inventory.md）

清单是写源稿之前的中间产物：读一章写一章，及时落盘。它保证覆盖完整，也让上下文被压缩后还能接着写。

```markdown
## 第4章 力系的平衡（64页）
跳过页：p1 标题（力系平衡⇔力满足的条件）；p31 标题+刚体系定义

知识点
- K4.6 平面任意力系平衡 p20,23-24：一矩式…；二矩式（A、B 连线不垂直 x 轴）；三矩式（A、B、C 不共线）
- K4.8 静定与超静定 p32-33：…

方法
- M4.2 平面任意力系：矩心取两未知力交点，一个方程一个未知；未用方程校核（p25, p26）

关键例题（可截图）
- E4.9 p26 雨蓬三支撑杆：ΣM_A: √2F1−5F=0 → F1=5F/√2；ΣM_C → F2=−4F；ΣM_D → F3=3F/√2。图 p26 右
```

要点：

- 每条都带页码；跳过页也写一句内容，便于核对覆盖。
- 例题记下已知数据、关键方程和结果，后面写源稿和重算时直接用。
- 看到课件里的"问题""思考题"也记下来，它们常常就是知识点的易错处。
- 公式用纯文本记即可（ΣM_A、√2），写源稿时再改成 LaTeX。
